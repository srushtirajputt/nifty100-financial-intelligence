# Nifty100 Financial Intelligence

A FinTech Data Engineering project focused on building a complete financial intelligence platform for Nifty 100 companies.

## Tech Stack

- Python
- Pandas
- PostgreSQL
- Power BI
- Django
- Docker
- Celery
- Redis
- GitHub

## Project Phases

1. Data Engineering Foundation
2. Power BI Dashboards
3. Machine Learning Scoring
4. Django Web Application
5. REST APIs
